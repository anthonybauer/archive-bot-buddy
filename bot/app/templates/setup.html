Setup Guide

1. Add the bot to your channel

  1. Open Telegram and go to your private channel.
  2. Tap the channel name at the top.
  3. Tap Edit → Administrators → Add Administrator.
  4. Search for {{ "@" ~ bot_username if bot_username else "your bot's username" }} and select it.

2. Permissions the bot needs

  • Post Messages — required, so it can upload videos.
  • Delete Messages — required, so it can remove the original link post.
  • Edit Messages — not required.

Then tap the check mark to save.

3. Find your Channel ID

Post any message in the channel and refresh this page.

4. Test it

Share an Instagram Reel link into your channel. Within a few seconds the bot uploads the video and deletes your link post. Check the Dashboard if something goes wrong.
