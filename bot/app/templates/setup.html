Setup Guide

1. Add the bot to your channel

  1. Open Telegram and go to your private channel.
  2. Tap the channel name at the top.
  3. Tap Edit → Administrators → Add Administrator.
  4. Search for {{ "@" ~ bot_username if bot_username else "your bot's username" }} and select it.

2. Permissions the bot needs

  • Post Messages — required, so it can upload videos.
  • Delete Messages — required, so it can remove the original link post.
  • Edit Messages — not required.

Then tap the check mark to save.

3. Approve the channel

Post any message in the channel, then open Dashboard → Channels. The channel appears under Pending. Click Allow — done.

How to add another Telegram channel

  1. Create or open the Telegram channel.
  2. Add this same bot as Administrator.
  3. Give it Post Messages and Delete Messages.
  4. Post any message in that channel.
  5. Open Dashboard → Channels.
  6. The new channel appears under Pending.
  7. Click Allow.

No SSH, no .env editing, no Docker restart.
